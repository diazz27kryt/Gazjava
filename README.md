# GazJava

Fabric-мод для **Minecraft Java 1.21.11** (`gazjava`, версия `0.1.0-alpha`): три газированных напитка,
вдохновлённых украинским «Живчиком». Это именно напитки (а не зелья) со своими текстурами, названиями,
рецептами и эффектами.

## Напитки

| Напиток | Эффекты длятся | Цвета | Рецепт (бесформенный, верстак) |
|---|---|---|---|
| **Газява Нефора** | 1 минута | фиолетовый + зелёный | 1 яблоко, 1 сахар, 1 стеклянная бутылка |
| **Газява Офника** | 5 минут | чёрный + красный | 2 яблока, 2 сахара, 1 бутылочка мёда, 1 стеклянная бутылка |
| **Газява Мотобрата** | 20 минут | чёрный + зелёный | 2 яблока, 2 сахара, 2 бутылочки мёда, 1 золотое яблоко, 1 стеклянная бутылка |

> **Про рецепт Мотобрата.** По заданию нужно 4 яблока + 4 сахара + 2 бутылочки мёда + золотое яблоко +
> бутылка — это 12 предметов, а в верстаке всего 9 ячеек, и в каждую ячейку кладётся по одному предмету.
> Поэтому количество яблок и сахара уменьшено вдвое (по 2), остальное — как в задании.
> Рецепт лежит в `src/main/resources/data/gazjava/recipe/gazyava_motobrata.json`.

Каждый напиток даёт **все** положительные эффекты: скорость, спешка, сила, повышение здоровья, регенерация,
сопротивление, огнестойкость, подводное дыхание, невидимость, ночное зрение, прыгучесть, поглощение,
медленное падение (уровень I; длительность зависит от напитка), плюс немного мгновенного лечения.
Также восполняется немного голода; пить можно даже с полной шкалой голода.

После питья (стандартная анимация питья) возвращается пустая стеклянная бутылка. В творческом режиме
напиток не расходуется и бутылка не выдаётся. Все три напитка есть в творческом инвентаре — во вкладке
«GazJava» и во вкладке «Еда и напитки».

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) для Minecraft 1.21.11.
2. Положите [Fabric API](https://modrinth.com/mod/fabric-api) (для 1.21.11) и `gazjava-0.1.0-alpha.jar`
   в папку `mods`.

Готовый JAR: вкладка **Actions** → последний успешный запуск `build` → артефакт `gazjava-jar`
(или раздел **Releases**, если выпущен тег `v*`).

## Сборка

Нужна Java 21.

```
./gradlew build
```

Результат: `build/libs/gazjava-0.1.0-alpha.jar` (файл `*-sources.jar` ставить не нужно).

Сборка в GitHub Actions: `.github/workflows/build.yml` — проверяет JSON/текстуры/рецепты
(`tools/validate_resources.py`), собирает мод, проверяет содержимое JAR, запускает настоящий сервер
Minecraft 1.21.11 с модом (smoke-тест: `tools/smoke_test_server.sh` + `tools/rcon_check.py`) и загружает
JAR как артефакт. При пуше тега `v*` JAR прикрепляется к релизу.

## Структура

- `src/main/java/com/gazjava` — код мода (`ModItems` — напитки, эффекты и механика питья; `ModItemGroups` —
  творческий инвентарь).
- `src/main/resources/assets/gazjava` — текстуры, модели, определения предметов, переводы (ru/en).
- `src/main/resources/data/gazjava/recipe` — рецепты верстака.
- `tools/generate_textures.py` — генератор пиксельных текстур (16×16); `tools/validate_resources.py`,
  `tools/smoke_test_server.sh`, `tools/rcon_check.py` — проверки.
